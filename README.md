# ClaimGuard

Agentic platform for auto-claims fraud investigation (synthetic and public data only).

**Status:** Sprint 0, project setup. Work in progress.

## Scope and limits
- Uses synthetic and licensed public data only; no real customer data.
- A human reviewer makes every consequential decision; nothing is denied, paid or cancelled automatically.
- Results are measured on synthetic and public data and do not show accuracy on a real insurer's claims.
