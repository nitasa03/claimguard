# AI assistant usage policy

Tools: GitHub Copilot, Claude Code, and Claude chat for design discussion.

1. I own the design. Architecture, requirements and decisions are written by me first.
2. I write the first version of the core pieces myself (SQL transforms, validation rules, one DAG). Assistants review or extend them.
3. I read every diff and run the tests before committing, and I can explain every line I commit.
4. No secrets, keys, real personal data or restricted datasets are pasted into a prompt or placed in the workspace.
5. AI-assisted changes are labelled in the commit message or pull request (what the assistant produced, what I verified or changed).
6. I check the license of any code I copy, whether it comes from a person or an assistant.
7. Assistant usage and cost are recorded in the daily log.
